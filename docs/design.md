# Design: mirror the desktop Console

The owner's desktop Console is the visual reference. `docs/console-reference.css` is its stylesheet
(reference only, not loaded). The web client must look like it, adapted for touch.

## Tokens
Use the Console's CSS variables verbatim (`--bg`, `--panel`, `--card`, `--card2`, `--line`, `--line2`, `--fg`,
`--muted`, `--accent`, `--accent-bg`, `--warn`, `--ok`, `--bad`, `--primary`, badge colours, `--r: 12px`,
`--font`), light and dark sets (dark via `prefers-color-scheme` and the manual toggle).

## Header and tabs
- Sticky header, blurred background, bottom border; logo square with the blue→violet gradient + «PRP».
- Tabs = segmented control: container `--card2`, padding 3px, radius 10px; tab buttons without borders,
  muted text, radius 8px; active tab `--panel` background + `--fg` + shadow (same as `nav button.on`).
- Phone (< 700 px): the same segmented control in ONE row, horizontally scrollable without a visible
  scrollbar, active tab scrolled into view; or a bottom tab bar with the same look. Never wraps.
- Sub-tabs (directions, morning steps): pills — 1px `--line` border, radius 999px; active `--accent-bg`
  with `--accent` border and 600 weight.

## Components
- Buttons: `.btn` (panel bg, 1px `--line2`, radius 9px, 7px 13px), `.btn.primary`, `.btn.small` (3px 9px, 12px).
  Touch: min-height 40px on phones.
- Rows (plan items, to-dos): `.row` — panel, 1px line, 4px left border in the kind colour, radius 12px,
  shadow; important `.row.imp` red left border + tinted bg; done → muted + line-through.
- Checkbox `.chk` 20px rounded square; on → `--ok`.
- Section headings `h2`: 12px, uppercase, letter-spacing .9px, muted.
- Cards/columns, badges, calendar cells (`.cal-d` lvl1–3), progress bars (`.pbar`, `.bbar`), toasts — as in the reference.

## Row actions (plan items and to-dos)
Right side of an open row shows only: the timer chip (`.timer`: time + ▶/⏸) and a `⋯` button (`.tbtn.more`).
- Tap on the time → opens the item in focus mode. ▶ starts the timer in place.
- `⋯` opens a small menu (`.rowmenu`) with labelled options: «⤢ Фокус», «💬 Комментарий / блокер»,
  «⭐ Важное» / «☆ Снять важное», and «→ Завтра» for plan items only (to-dos have no «→ Завтра» and no «→ идея»).
- No text buttons in the row itself. Long-press (touch) / right click toggles ⭐ important.
- Comment / blocker fields stay hidden unless filled or opened from the menu; any open item can have them.

## Focus mode
One item full-screen (`.focus-card`): kind line, big title, task text, links, big timer — tap on its time to
type the length (default from settings, 20 min) — comment/blocker always visible, buttons «✓ Готово»,
«→ Завтра» (plan items only), «Пропустить», «✕». Order: open tasks → to-dos → learning → projects.
Done / tomorrow move to the next open item; at the end «На сегодня всё».

## Instant request
The help text under the input is hidden behind a small «?» next to the heading.

## Ideas tab (mirror the Console)
- Top: status filter pills with counts — «все (N)», «новая», «нравится», «проверка», «пауза», «готово», «✕ отсеяно»
  (all = everything except dropped) + a select «все направления» (areas from config/areas.yaml).
- One card per idea (newest last_touched first): title (tap → detail view); meta line «<purpose ru> · <area title> ·
  <status ru> · от агента|от владельца»; «Риск: <main_risk>» line if present.
- Card actions in one row: reaction buttons 👍 (liked) / 🧪 (testing) / ✕ (dropped) / ⏸ (paused) — the current
  status is highlighted; an input «✎ правка (Enter — в карточку)» (appends to `## Комментарии владельца` and
  updates last_touched); on the right «+ на сегодня» (adds a plan item with ref, kind idea, 25 min) or
  «в плане ✓» when today.json already has an open item with this ref.
- Today's ideas from today.json (unreacted) stay on «Сегодня», as in the Console — not on this tab.
- Status ru: new «новая», liked «нравится», testing «проверка», paused/parked «пауза», done «готово», dropped «отсеяно».

## Loading speed
Lists (Directions, Ideas, Today's refs) come from `objects.json` (one request, see docs/lab-schema.md);
a single object's `.md` is fetched only for its detail view or when writing it. Show cached data from the
last session immediately (localStorage, per data repo), then refresh in the background (ETag / If-None-Match).
After a write, patch the in-memory list from the written file — objects.json is regenerated by CI ~30 s later.

## «Утро» / «Итоги» (mirror the Console's ☀ tab)
One tab «☀ Утро», first in the tab row. From 22:00 to 04:00 it shows «🌙 Итоги» instead (the plan before 04:00
still belongs to yesterday). Both are step-by-step with pills on top (`.msteps`: past / current / next),
«Дальше →» and «← Назад» at the bottom; steps can be jumped to by tapping the pill.

### ☀ Утро — 5 steps
1. **Сводка** — cards: «Вчера» (done/total · minutes from the latest `history/<day>.json` before today, postponed count),
   «Сегодня в плане» (open items · planned minutes of `budget_minutes`, learning minutes), «Идеи дня» (N waiting
   for a reaction / «разобраны»), «Codex» (N on review / changes, ready count). Link to the brief.
2. **Хвосты** — open items with `carried` or `blocker`: «оставить» (hide for this session), «→ завтра», «убрать».
3. **Идеи** — unreacted `today.ideas`: title, summary, 👍 / 🧪 / ✕, «✎ правка» (Enter).
4. **Сборка дня** — budget bar (planned / budget); «💡 Идеи дня» again if any are still unreacted; «В плане» list
   with «→ завтра»; «Добавить проектную работу»: `today.candidates` (not ideas, not already planned) + active
   projects' `next_step` → «＋ N мин» adds a plan item (`ref`, kind, minutes, `task`); «🧪 Тесты»: experiments
   planned/running and ideas with status testing that have no experiment yet — «＋ 45 мин», and for ideas
   «🤖 агентам» which fires the instant request `test: <idea id>` (shows «у агента ⏳» after); «🤖 Отдать Codex»:
   codex.json tasks ready/changes with «📋 скопировать».
5. **Старт** — budget bar, first task, «▶ Начать день» → «Сегодня», «⤢ сразу в фокус».

### 🌙 Итоги — 5 steps
1. **Итог дня** — bar of minutes; cards: «Сделано» N of M (+ minutes by timer), «Задачи · Обучение · Проекты» done/total
   per group, «Дела из списка» done today, «Codex влито» today.
2. **Несделанное** — open items: «→ завтра» (postpone), «снять» (remove).
3. **Где остановился** — one input per object referenced by today's items (project / learning / experiment, not
   done/dropped, not `resume: false`): Enter writes the text into the object's `## Где остановился` section,
   updates last_touched, journal line, and stores it in `today.evening.notes` [{ref, text}].
4. **Тесты** — 🧪 ideas of the day + experiments planned/running: «＋ завтра · 45 мин» adds a `postponed` entry
   with `until` = tomorrow.
5. **Завтра** — draft: postponed items for tomorrow (with budget bar), next steps of active projects;
   «✓ Итоги подведены» sets `today.evening.done_at` (local ISO minutes).

## Object editor (side drawer, mirror the Console)
Opening any object (tap on a plan item title on «Сегодня», a card in «Направления» / «Идеи», a calendar ref)
slides in a right-side drawer over the current tab (`.drawer` in the reference CSS; full-screen sheet on phones),
instead of navigating away. ✕ / Esc / tap on the dimmed backdrop closes it; the URL hash keeps `#<tab>/<path>` so
back/forward and reload work. Contents, top to bottom:
- meta line: type icon · type ru · path;
- «Название» input;
- three selects: «Направление» (areas from config/areas.yaml), «Статус» (statuses of this type, ru labels),
  «Цель» (money / interest / learning / useful → заработок / интерес / обучение / польза);
- «Следующий шаг» input;
- type fields, two per row: project — goal «Цель», blocked_by «Что блокирует»; learning — progress «Прогресс»,
  cadence «Режим (напр. daily 30 min)», platform «Платформа», location «Где материал», why «Зачем»,
  start_date «Старт (ГГГГ-ММ-ДД)»; idea — quick_test «Быстрый тест», success_signal «Сигнал успеха»,
  main_risk «Главный риск»; experiment — hypothesis «Гипотеза»;
- project only: «Задачи» checklist from `## Задачи` (tick, «＋ сегодня», ↑, ✕, input «Новая задача проекта (Enter)»);
- «Содержание (markdown)» — a textarea with the body (everything after the front matter), monospace;
- buttons: «Сохранить» (primary: writes the front matter fields + body in one commit, updates last_touched, journal
  line as a second commit), «В план на сегодня» (plan item: title = next_step or title, ref, kind, 25 min),
  «🤖 → Codex» (project / idea / experiment / learning: opens the Codex task form in «Ещё» prefilled with this ref),
  «🎓 Собрать курс» (learning: copies «собери курс <id> по скиллу course-builder» and opens
  https://claude.ai/code in a new tab), «↗ в Claude Code» (copies
  «продолжим <id>» / «разберём <id>» and opens https://claude.ai/code in a new tab). No «Чат с агентом» on the web.
- footer: «Создано … · изменено … · source · от агента».
Unknown front matter keys are preserved untouched on save (round-trip of the front matter module).
